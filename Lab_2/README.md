Задание A1
Даны переменные ширины (целое число 17) и высоты (вещественное число 12.0). Для четырех заданных выражений (целочисленное деление ширины на 2, деление ширины на вещественное число 2.0, деление высоты на 3, а также комбинированное выражение со сложением и умножением чисел) необходимо определить итоговое значение каждого выражения и его получившийся тип данных.
Задание A2
Дан список из восьми различных выражений (строки с буквами, строки с точками, арифметические операции со строками, вещественные числа, а также математические операции с возведением в огромную степень). Требуется определить, какие из этих выражений можно успешно преобразовать в целое десятичное число за одно применение стандартной функции перевода типов, какие приведут к ошибке и по какой причине. Также необходимо зафиксировать конкретные названия ошибок, которые выдает среда выполнения.
Задание A3
Известно, что число 3 в степени 9090001 занимает в памяти компьютера ровно 1 921 000 байт. Требуется написать программу, переводящую это значение в мегабайты, исходя из правила: в одном килобайте содержится 1024 байта, а в одном мегабайте — 1024 килобайта. Для проверки вычислений необходимо использовать специальную системную функцию, определяющую реальный размер созданного в памяти объекта в байтах, и сравнить полученные результаты.
Задание A4
Необходимо запросить у пользователя два целых числа в диапазоне от 1 до 1000 и определить, какое из них является наибольшим. При написании программы накладывается строгое ограничение: разрешено использовать исключительно базовые целочисленные арифметические операции. Любые нелинейные конструкции, такие как условные операторы, циклы или встроенные функции выбора максимума, использовать запрещено. Задачу предлагается решить с помощью работы со списками или через тернарное выражение.
Задание A5
Программа принимает на вход два целых числа. Требуется определить, делится ли первое число на второе нацело без остатка. На решение накладываются аналогичные ограничения: запрещено использовать стандартные ветвления и условные операторы. Если первое число кратно второму, программа должна вывести утвердительный ответ, в противном случае — отрицательный.
Задание A6
На вход программе подается целое число секунд, прошедших с начала текущих суток. Требуется перевести это время и отобразить его в формате электронных часов, где сначала выводятся часы (от 0 до 23), а затем обязательно двузначные минуты и двузначные секунды (с ведущими нулями при необходимости). Использовать строковые типы данных разрешено только в самый последний момент для форматированного вывода результата на экран.
Задание A7
Пользователь вводит координаты двух случайных клеток на шахматной доске (каждая клетка задается номерами столбца и строки). Программа должна определить, одинакового ли цвета эти клетки. Если цвета совпадают, требуется вывести утвердительный ответ и конкретное название цвета (белый или черный), учитывая, что стартовая клетка с координатами (1,1) является белой. Если клетки разных цветов, выводится только отрицательный ответ.
